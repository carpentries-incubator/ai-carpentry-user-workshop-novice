[AI Carpentry][aicarpentry] empowers researchers to make informed use of AI.
This workshop aims to teach researchers with no previous experience of programming the basic concepts and skills they need to begin applying AI-assisted coding in their projects.
After following the workshop, learners will be able to critically evaluate coding outputs generated by an AI chatbot and plan the next steps to continue building their expertise.

::::::::::::::::::::::::::::::::::::::::::  prereq

## Getting Started
This workshop assumes no prior experience with the tools covered in the workshop.

To get started, follow [the setup instructions](#setup) to get access to the required software for this workshop.

# Workshop Overview

| Lesson | Overview | 
| ------ | -------- |
| [Exploring Large Language Models](https://carpentries-incubator.github.io/llms-intro-novice/) | Learn how large language models work, as the central technology of generative AI coding tools, and about the role payed by randomness in their outputs. | 
| [Considering Implications of GenAI Use](https://carpentries-incubator.github.io/genai-implications-novice/) | Discuss the implications of the development and use of generative AI, and reflect on how this could influence when and how you choose to use these tools. | 
| [Learning Programming with GenAI](https://carpentries-incubator.github.io/coding-with-llms-novice/) | Get started with programming, using a chatbot to explain, create, and modify code, and develop strategies to remain in control of your research. |
